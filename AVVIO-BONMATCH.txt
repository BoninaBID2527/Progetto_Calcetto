BONMATCH - AVVIO RAPIDO
=======================

Serve: Node.js 20 o piu' recente (consigliato 22) e Docker Desktop.
Apri TRE finestre di PowerShell nella cartella del progetto.

FINESTRA 1 - MongoDB
--------------------
docker compose up -d

FINESTRA 2 - Backend (API su http://localhost:4000/api)
-------------------------------------------------------
cd backend
Copy-Item .env.example .env
npm install
npm run seed
npm run dev

FINESTRA 3 - Frontend
---------------------
cd frontend
npm install
npm run dev

Poi apri il browser su:  http://localhost:5173

-------------------------------------

npm install
npm run migrate        (sicuro da rilanciare: non cancella nulla)
Poi riavvia il backend e, in frontend, "npm install".

SENZA DOCKER (solo per una prova veloce, dati in memoria)
--------------------------------------------------------
Nella FINESTRA 1, al posto di "docker compose up -d":
cd backend
npm run db:lite


PROBLEMI FREQUENTI
------------------
"MongoDB non risponde"   -> Docker Desktop e' acceso? Riprova "docker compose up -d".
Porta 4000 o 5173 occupata -> chiudi l'altra applicazione o cambia PORT nel file backend\.env.
Pagina bianca            -> controlla che il backend (finestra 2) sia acceso.
